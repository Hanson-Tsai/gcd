# gcd

GitHub Cloud Disk: sync a local folder with a private GitHub repo. See issue #1 (https://github.com/Hanson-Tsai/gcd/issues/1) for the v1 spec.

## Agent skills

### Issue tracker

Issues live in GitHub Issues of Hanson-Tsai/gcd, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five triage labels plus a repo-specific `done` label for completed issues. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
